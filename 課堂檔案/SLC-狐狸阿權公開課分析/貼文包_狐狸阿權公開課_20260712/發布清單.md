# 發布清單 — 狐狸阿權公開課（20260712）

> 這份清單是「手動發布」的操作依據。技能只負責產出素材，實際上傳與送出請由本人完成，
> 以便最後一次確認肖像與內容無誤。

## 一、發布前檢查（每次都要過一遍）
- [x] 肖像已處理：本包全部素材為 **(c) 重繪插畫**（依公開課影片影格重繪的水彩繪本風插圖，無可辨識真人、無口罩、無觀課者）
- [ ] 重繪插圖為「示意插畫」，非紀實照片——貼文文案已以「課例分享」定位，不會被誤認為本校活動紀實；若需正式對外報導仍請搭配文字說明
- [x] 文案中的事實皆出自課例分析（時間、對話、圖表活動均有逐字稿與時間碼可查），無 AI 填空的數字或名次
- [ ] 若想標註學校，請自行在 hashtag 加上校名（目前僅用 #新北市 與通用教育標籤）
- [ ] 建議在 FB 文末或留言補一句素材來源說明（例：「圖為依公開課影片重繪之示意插畫」），更周全
- [ ] 錯字、標點檢查一遍

## 二、素材對應（哪張圖配哪段文）
| 平台 | 文案檔 | 搭配圖／影片 | 建議發布時間 |
|------|--------|--------------|--------------|
| Facebook | `FB.txt` | `封面.png`（首圖）＋`引言卡.png`＋可加選 `IG輪播/01–08.png` | 晚上 20:00–22:00 |
| Instagram | `IG.txt` | `IG輪播/01.png` 至 `08.png`（依序輪播，共8張，皆 1080×1350）＋`引言卡.png` 可插入為第9張 | 晚上 20:00–22:00 |
| Reels | `Reels說明.txt` | `reels_相片影片.mp4`（39秒、1080×1920）＋字卡見 `Reels腳本.txt` | 週末白天 |

IG 輪播順序＝故事線：01 起立問候 → 02 朗讀 → 03 指圖低語 → 04 小組討論 → 05 全班分享 → 06 翻書查證 → 07 舉起圖表 → 08 下課致意。

## 三、逐平台發布步驟
### Facebook
1. 開啟粉專 → 建立貼文
2. 貼上 `FB.txt` 內容
3. 上傳 `封面.png`（可加 `引言卡.png` 成雙圖）
4. 確認預覽 → 發布

### Instagram
1. 新貼文 → 選 4:5 直式
2. 依序上傳 `IG輪播/01.png` ~ `08.png`（可將 `引言卡.png` 排在最後收尾）
3. 貼上 `IG.txt` 內容
4. hashtag 可放說明或首則留言 → 分享

### Reels（IG／FB）
1. 上傳 `reels_相片影片.mp4`
2. 影片無配樂：請在平台內建音樂庫挑一首輕柔鋼琴／Lo-fi（無版權疑慮）
3. 用平台文字工具依 `Reels腳本.txt` 逐段疊上字卡（放畫面下 1/3、避開最底部 15%），或請我直接燒錄字卡版
4. 貼上 `Reels說明.txt` → 選封面（可用影片第 10–15 秒的指圖畫面）→ 分享

## 四、發布後
- [ ] 隔天看一次觸及與留言，記錄哪種內容反應好（供下次調整）
- [ ] 教育同行若詢問課例細節，可分享簡報連結或 `output/analysis.txt` 的重點段落

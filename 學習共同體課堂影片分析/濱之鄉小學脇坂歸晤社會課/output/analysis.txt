# 課堂主題與單元背景
- 課例名稱：濱之鄉小學社會課「汽車產業的發展」
- 授業教師：脇坂歸晤老師，為日本學習共同體的重要實踐者
- 課程定位：15課時單元中的第13課，探討產業全球化
- 核心探討：探討國內生產與海外生產在經濟與社會層面上的全球化兩難

# 課前複習與價值引入
- Miyu爸爸（安全氣囊開發業者）的課堂分享回顧
- 核心理念：除了賺取利潤，保障「人的生命安全」是更重要的價值
- 課堂觀察：將學生觀課感想整理成列表，引導學生思考生命價值的優先性

# 衝突情境：國內生產的立場與心聲
- 描述：Misaki的父母在國內製造引擎，若生產線移往海外，日本國內的相關工廠將面臨倒閉與失業
- 詮釋：學生將個人家庭故事與課堂主題連結，產生強烈的同理心與代入感
- 反思：透過身邊人的故事打破知識的冰冷性，建立有溫度的學習起點

# 衝突情境：海外生產的經濟邏輯
- 描述：海外生產能降低人事與材料成本，讓產品更便宜且具備國際競爭力
- 詮釋：學生從大企業如豐田的存續角度思考，若母公司不賺錢，整體經濟下行將波及更多家庭
- 反思：引導學生理解在資本主義經濟運作中，成本控制與企業生存的客觀規律

# 小組協同學習：傾聽與對話的展開
- 描述：教師設計小組交流時間，讓每位學生在小組中發表對生產策略的個人看法
- 詮釋：藉由協同學習避免少數活躍學生壟斷發言的狀況，確保每個孩子都不是學習的「客人」
- 反思：小組中「溫柔地傾聽」比「大聲地發表」更為關鍵，這是學習共同體的哲學基礎

# 個人情感與社會整體的掙扎
- 描述：多數學生的想法是「我個人希望留在國內生產以保護工作，但考慮到社會整體，不得不移往海外」
- 詮釋：學生的思維開始分層，理解個人情感與宏觀經濟策略之間的衝突
- 反思：教學設計成功引導學生走出單一視角，看見複雜社會現象背後的「兩難（Dilemma）」

# 澳洲豐田關廠案：真實案例的衝擊
- 描述：教師引入2014年《日本經濟新聞》報導：豐田將於2017年撤退澳洲工廠，導致2500人失業
- 詮釋：真實的新聞事件打破了「海外生產是一勞永逸的解方」之迷思，帶來二度認知衝突
- 反思：利用時事教材（報紙）作為學習的「跳躍（Stretch）」鷹架，引領學生進行更深層的思辨

# 澳洲豐田案例的小組深入探究
- 描述：學生小組探討關廠時間差（2014-2017）的用意，以及失業對當地家庭和日本名聲的影響
- 詮釋：學生自主連結「失業背後代表無數個需要被養活的家庭」，展現對他國勞工的同理心
- 反思：協同學習在此階段發生了「伸展跳躍」，從討論日本國內問題延伸至全球化背景下的企業責任

# 日本技術傳承與母公司生存之辨
- 描述：探討若技術全數外流至海外，日本國內可能無法保全核心競爭力；但若不外移，母公司恐面臨生存危機
- 詮釋：學生理解這是一場「沒有標準答案的掙扎」，豐田社長的決定也是歷經艱難的取捨
- 反思：引導學生體會「兩難處境」是真實世界的常態，學習做出深思熟慮的判斷而非輕率的二分法

# 聆聽關係的微觀觀察
- 描述：在學生發言緩慢或遲疑時，全班與教師都耐心等待，給予足夠的時間讓孩子將想法化為文字
- 詮釋：等待的靜默空間創造了安心的學習氣氛，每個孩子都有發言的生存空間，並得到他人的認可與同理
- 反思：教師的聆聽姿態決定了課堂的品質，以「傾聽」取代「發問」，能促進更平等的對話

# 人口結構與海外生產的伏筆
- 描述：教師在課堂最後展示「日本人口預測圖」，指出勞動力人口（15-59歲）將在2055年大幅減少
- 詮釋：引發學生對於人口老化、少子化如何影響產業全球化佈局的全新問號
- 反思：本堂課不以「標準答案」作結，而是留下懸念，將學生的思考延伸至下一堂課

# 學習共同體課例實踐總結
- 聆聽關係的建立：師生共同營造互相信任、安心發表與相互傾聽的學習場域
- 協同合作的設計：透過生活故事與時事報紙，設計挑戰性的兩難問題，激發協同思維
- 反思與延伸：以大問號結尾，促成自主探究的持續性，展現「主動、協同、深探」的學習品質

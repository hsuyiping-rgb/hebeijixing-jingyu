# 脇坂老師社會課(2018)：宮瀨水庫
- 課例研究：描述－詮釋－反思三階層分析
- 觀課單元：五年級社會科，水庫建設與補償金的價值思辨（單元第三堂課）

# 一句話看懂這堂課
- 這是一堂沒有標準答案的社會課：學生透過反覆聆聽水庫遷居者陸和先生的訪談聲音，在「故鄉能否用錢衡量」的辯證中，一次次修正、甚至推翻自己原本的立場。

# 課程任務的脈絡設計
- 本堂課是單元的第三堂，承接前兩堂已建立的訪談資料基礎（00:38）
- 因故缺席的學生促成教師重播訪談影片，形成全班共同復習的自然契機（01:19、11:19）
- 任務主軸：「若你是宮瀨的住民，你會贊成還是反對建水庫？」貫穿全堂（21:17）

# 描述：教師開場的立場宣示（00:00–02:01）
- 教師開宗明義：社會課不是「零跟一」的問題，不是對或錯，而是充滿沒有正確解答的模糊地帶
- 這段開場先於任何具體案例出現，等於為全堂課預先鬆動「找到正確答案」的預設心態
- 教師提及自己曾實際走訪當地居民進行採訪，將田野證據帶入課堂

# 描述：學生初次表態時的猶豫語言（03:36–07:00）
- 多位學生依序發言，語言中充滿「但是」「不曉得該怎麼想」等猶豫用詞，而非直接的贊成／反對宣告
- 有學生說能感受到受訪者的難受，卻仍認為水庫「還是需要的」，兩種情感同時並存
- 也有學生坦言自己曾經反對，語氣中保留立場轉變的可能性

# 描述：學生聽出訪談聲音裡的情感線索（05:02–05:16）
- 一名學生特別指出：聽陸和先生訪談時，「聲音很難過」，且這份難過像是延續到現在還記得當時的痛苦
- 這是學生從語言內容之外，捕捉到語氣、聲調等副語言線索的具體時刻

# 描述：學生指認自己是他人犧牲的受益者（05:29）
- 同一名學生接著說出：「是因為陸和先生他們這些住民的犧牲，讓我們茅崎這邊有水可以用，所以我們也要很感謝他們」
- 學生在此把訪談對象的失去，與自己每天使用的自來水直接接上，遠端的公共建設議題被拉回到自身生活
- 這是全堂唯一由學生主動說出「我是這場犧牲的受益者」的時刻，也是後續價值思辨得以站立的基礎

# 描述：重播訪談，鋪陳具體生活細節（08:16–13:14）
- 教師為缺席學生重播對陸和先生的訪談：社區規模、氣候、颱風淹水經驗、遷居35年後仍不認同新居地為「故鄉」
- 訪談中出現具體且反覆的畫面描述：水位上漲、房屋逐漸被淹沒的親身經歷
- 這些細節讓「贊成或反對」的抽象立場，重新錨定在一個真實個人的生命經驗上

# 描述：教師板書即時連結學生發言（14:33–18:41）
- 教師一邊聆聽學生發言，一邊在黑板上書寫記錄，學生也同步記下同儕發言中自己覺得有意思的論點，而非照抄教師的板書
- 多位學生在小組內重複說出「我自己也沒想到」，呼應前一位發言者的觀點
- 全班的傾聽姿態被觀察者兩度指認出來：「他們好會聽，每個都轉過去聽，大家都想知道互相的意見」（18:37）、「好會聽啊，每個轉過來都聽」（27:05）——轉身面向發言者是學生自發的動作，並非教師當場下的指令

# 描述：小組深入討論的展開（21:05–24:38）
- 教師明確轉換任務形式：「那現在老師要你在小組裡面再去做深入的討論」（21:17）
- 小組內出現分歧路線：有學生說「先拿補償金，之後再看要不要搬家」（22:28），呈現務實策略；也有學生主張故鄉若能用錢買到「那就不像故鄉兩個字了」（22:53），呈現價值堅持
- 另一名學生把兩條路線收攏成一組對比：「我覺得不是錢的問題，我覺得是心的問題」（23:39）
- 教師巡視小組間，適時把個別對話「抓回」全班焦點（24:18）

# 描述：從補償制度到具體數字的揭露（29:05–33:11）
- 教師先說明補償的完整內容：不只給錢，還包含職業補償、生活補償、土地補償與新居保障（29:05–30:00）
- 再以鄰近的三保水壩作為對照基準：223戶、227億元，每戶約1億元（31:45）；接著揭露宮瀨的實際金額：281戶、500億元，平均每戶近1億8千萬元（32:13–32:22）
- 學生反應明顯轉為驚訝：「這麼多啊」「一百萬都不到一億耶」
- 這個具體數字的出現，把原本停留在情感層次的討論，推入了更複雜的量化衡量情境

# 詮釋：傾聽關係——從內容到聲音的深化
- 教師的角色從知識權威轉為傾聽的催化者
- 學生捕捉受訪者聲音中的痛苦（05:02），顯示傾聽的對象已超越語意內容本身，進入語氣、停頓、情緒等副語言層次
- 這種傾聽品質並非教師直接教導的技巧，而是在反覆聆聽訪談錄音的過程中逐漸養成的敏感度

# 詮釋：漣漪效應——「我自己也沒想到」的擴散路徑
- 「對話漣漪」在此發生：一句猶豫的發言（而非正確答案）成為漣漪的起點
- 「我自己也沒想到」在十六秒內連續出現六次（17:52–18:08），顯示的不是內容抄襲，而是同一份「未曾設想」的驚訝感在同伴間層層擴散
- 教師的板書箭頭（28:08）將這種擴散具象化，讓原本流動、不可見的對話漣漪變成可見的思考地圖

# 詮釋：言談權力的重新分配
- 教師全堂沒有給出「正確立場」，而是以問題引導（「你贊成嗎」「大家覺得怎麼樣」）不斷把發言權交還學生
- 學生記錄同儕發言而非教師板書內容（14:50），是言談權力從教師往學生水平流動的具體證據
- 教師的角色更接近訪談紀錄的「轉譯者」，而非立場的仲裁者

# 詮釋：伸展跳躍任務——情感立場到量化衝突的躍升
- 補償金數字的揭露（31:45起）製造了一次明確的認知衝突：原本的情感立場（故鄉不能用錢衡量）必須與具體數字（近2億元）正面交鋒
- 這是一個精心佈局的伸展跳躍點：學生被迫在「已建立的價值堅持」與「新出現的現實資訊」之間重新協商
- 學生的反應並非立場崩潰或全面翻轉，而是延伸出更細緻的區辨——「不是錢的問題，是心的問題」（23:39）這組由學生自己提出的錢／心對比，讓討論得以在承認金額之後仍然繼續

# 詮釋：認同建構——「故鄉不能重造」的辯證
- 「學習即認同建構」：學生並非單純記憶水庫遷居的史實，而是在建構自己對「故鄉」這個概念的理解
- 一名學生提出「故鄉不能重造」（42:35）反駁另一派「搬到相似環境重建同樣社群」的樂觀方案，兩種立場在課堂上被公開並置、不急於收斂
- 這種懸置、不強制達成共識的討論方式，呼應「去評價、去建言」的課例研究立場——教師沒有替學生決定哪個答案更正確

# 詮釋：潤澤的教室——安全承接立場轉變
- 教師的核心宣示（34:56–35:45）：社會有很多灰色的模糊地帶，社會科的重點不是教是非，而是要用很多角度的觀點去看同一件事情
- 這句話為整堂課的立場搖擺（贊成→反對→再猶豫）提供了安全感，學生不需要擔心改變想法會被視為「答錯」
- 多次出現「我本來是贊成的，但現在反對了」的發言，顯示教室氛圍容許學生公開修正自己

# 反思：這堂課的優勢
- 將抽象的價值思辨（故鄉、金錢、公共建設）錨定在真實受訪者的具體生命經驗與聲音細節上，避免討論流於空泛的立場表態
- 補償金數字的延遲揭露，是有意識的認知衝突設計，讓討論從情感層次自然過渡到更複雜的多維度思考
- 板書連結與小組任務的交錯安排，讓個人思考、同伴對話、全班共享三個層次緊密銜接

# 反思：可以再精煉之處
- 逐字稿顯示課堂中存在明顯的沉默與遲疑片段（如15:55–16:18的多次停頓語），這些「質性時間」的教育意義值得更深入的分析，而非僅視為對話的空隙
- 部分小組討論片段因收音距離而語意模糊，難以完整還原每位學生的發言脈絡，是這次課例研究資料本身的限制
- 教師在揭露具體數字後的接續提問，可以再更明確地邀請學生說出「立場為何改變／未改變」的後設思考

# 可移植的教學策略
- 為缺席學生重播先前訪談素材，順勢成為全班共同復習的機會，而非額外負擔
- 以真實人物的第一手聲音（而非教科書摘要）作為情感錨點，再延遲揭露關鍵數字製造認知衝突
- 教師以板書箭頭將分散的學生發言可視化連結，讓抽象的「傾聽」轉譯成具體可見的思考地圖
- 課堂尾聲保留明確的個人反思書寫時間，讓40分鐘內反覆搖擺的立場得以沉澱整理（46:25）

# 觀課結論
- 這堂課的核心不在於「該不該建水庫」是否得到答案，而在於學生如何在傾聽真實聲音、同伴對話漣漪、與具體數字衝突之間，逐步建構起自己對「故鄉」與「公共犧牲」的理解
- 教師的核心作為，是設計出足以承接複雜性的提問與傾聽結構，並讓「沒有答案的問題」保持開放到課程結束

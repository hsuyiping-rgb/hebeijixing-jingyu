# 素材使用建議 — 宮瀨水庫：錢與心

建立日期：2026-07-26

## ⚠️ 一處與原始逐字稿不同的用字，請確認

逐字稿只說「500 億」「一億八千萬」，**沒有講幣別**。本文案包一律寫成
**「日圓」**。

理由：這是日本神奈川縣宮瀨水庫的政府補償金，必然是日圓。若沿用逐字稿的
「元」，台灣讀者會直覺理解為新台幣——1.8 億日圓約合 3,800 萬新台幣，
差距近五倍，是會誤導人的數字。

如果你希望完全貼合逐字稿字面，改回「元」即可，但建議至少在文末補一句
幣別說明。

## 一、三條護欄（發布前逐項確認）

1. **只用 AI 插圖，不用原始影格**
   `output/screenshots/` 裡是可辨識的真實日本小學生臉孔。短影音傳播範圍
   遠大於簡報，不要為了「真實感」破例。

2. **學生發言標明是中文口譯**
   這支影片是日文原課的中文口譯覆述版，字面不等於課堂原話。金句
   「不是錢的問題，是心的問題」出自 23:39 的口譯。收尾卡與各平台文案
   都已加註，請勿在編輯時刪除。

3. **插圖標示為 AI 重繪**
   避免被當成實際課堂紀錄流傳。

## 二、直式插圖需求（12 張，1080×1920）

現有 `output/images/` 是 1672×941 **橫式**，直接裁成 9:16 會砍掉約 70%
畫面寬度。這批圖是「全班散布在畫面各處」的教室廣角，裁完只會剩中間兩三
個學生，構圖會垮。**建議重生 12 張直式圖**，不要裁切。

重繪原則沿用 `output/illustration_mapping.md`：

- 同一位授課教師：35–40 歲男性、白襯衫深色長褲、**無眼鏡**
- 同一班學生，服裝特徵延續（綠色上衣、紅色球衣、粉紅外套等）
- **移除外圍觀課教師、攝影機與旁觀者**，只留學生與授課教師
- 溫潤的日本小學課堂水彩風
- 圖內不放文字、字幕、Logo 或頁碼
- 直式構圖要點：主體置於畫面上三分之二，下三分之一留給字幕

各 cue 的構圖指示見 `Reels_腳本.txt`。

## 三、影片與字幕規格

| 項目 | 規格 |
|---|---|
| 解析度 | 1080 × 1920（9:16） |
| 幀率 | 30 fps |
| 長度 | 30.0 秒 |
| 編碼 | MP4 / H.264 |
| 音軌 | 必須有 AAC 音軌，即使無聲 |

| 字幕 cue | 12 個，每個 2.5 秒 |
| 字幕長度 | 每句 ≤ 15 字，單行 |
| 字幕位置 | 下三分之一，避開最底 15%（平台 UI 遮擋區） |

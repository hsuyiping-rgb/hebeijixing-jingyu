## ❌ 日文字幕：技術上不可行（已充分驗證，勿再嘗試）

使用者一度要求做中日並呈字幕。**結論是這個影片檔無法還原日文原音**，已決定維持中文單語。以下記錄避免重踩。

### 影片的實際結構
- 單一音軌，左右聲道差值 −54 dB → 兩聲道相同，**沒有可分離的原音軌**
- YouTube 端無任何字幕、無多語言音軌（139/140/251 都是同一條混音）
- 播放結構是「日文原話 → 中文口譯緊接覆述」，中文口譯是主導人聲

### 試過而失敗的方法
1. **直接強制 `--lang ja` 轉錄** → 純幻覺，輸出混入「離開家庭」「上次」「土石流」等中文詞，是 Whisper 在追中文語者的鐵證
2. **抓中文 word-level 空隙（98 個、共 798 秒）串接後轉錄** → 撈出的「日文」在重轉時完全不重現，是接縫幻覺
3. **雙通道交叉比對**（切塊位置錯開 60 秒各跑一次全片）→ 44 段通過，但清一色是中文口譯的假日文（「水壩は必要なのです」「怪怪的なのです」「社会課は何か」「失去家の痛苦」）

### 三道判準為何全部失效
- **信心分數不可用**：驗證為真的句子 avg_logprob 只有 −0.71，完全沒重現的幻覺卻高達 −0.055
- **重現性不可用**：兩趟聽的是同一段真實中文音訊，所以會穩定產生同一種假日文。重現性只證明「音訊是真的」，不證明「日文是真的」
- **假名比例不可用**：「水壩は必要なのです」假名占比 0.56 照樣過關

### 決定性證據
同一段音訊（12:49–12:55）三次轉錄結果完全不同：
```
第一次   水が来ました / もうちょっとで自分の家まで水が来る
Pass A   沙櫓が来るが / 私たちは、まあ、これがここまで来た…
Pass B   水が一般的に来ています / もう少しだけで私の家もないです
```
語意重複（因為口譯內容穩定）但字面永遠不同 → Whisper 並非在轉寫任何實際說出口的日文，而是在把中文語意每次重新改寫成破碎日文。

### 若日後仍要做日文字幕，只有兩條路
1. **找日文原版影片**：這支是日本課例研究影片的中文口譯版。可循東京大學 CoREF、授業記錄 DVD、學校公開授業資料等管道找「濱之郷小学校・脇坂圭吾・宮ヶ瀬ダム・社会科」原版。這是唯一能取得真日文原音的方法。
2. **中文字幕回譯成日文**：時間碼可完全對齊、可立即完成，但必須在字幕檔標明「本日文為中文口譯之翻譯，非課堂原話」，**不得作為逐字稿引用**。

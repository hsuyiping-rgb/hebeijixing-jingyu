## 教學設計理念

課本 p.49 的銅球銅環實驗把固體熱脹冷縮做得乾淨俐落：加熱三分鐘，銅球卡在銅環上；浸冷水，又穿過去了。步驟、結果、結論句全都印在頁上，學生照做就會得到「固體會熱脹冷縮」這句話。

但這句話裡的「脹」，學生只知道它會發生，不知道它往哪裡去。問他們「銅環加熱會怎樣」，多數人會直覺回答「洞會變小」——因為金屬往內脹、把洞擠掉了。這個直覺是錯的，而且錯得很自然；課本 p.48 的鐵軌、橋梁、瓷磚縫隙全在講固體「往外」脹，卻沒有任何一頁讓學生把「有洞的固體」想過一遍。

本節就把這一題交給學生：銅球加熱卡住之後，不浸冷水，改把銅環也加熱，銅球會過、更卡、還是一樣？先各自預測寫理由，小組選一種說法上牆，再點蠟燭驗證。教師不預告答案、不在預測階段裁決哪一派對；三派的理由要在全班面前並排，讓實驗結果去撞它們。結果出來後追的不是「誰對」，而是「銅球在等的時候會不會涼掉？你怎麼確定是銅環的功勞？」——這一步把六年級的「做實驗」推向「設計能說服人的實驗」。

## 教材組織與學生分析

**一、文本結構分析**

```
單元節次   活動1-1 液體(p.44–45) → 1-2 氣體(p.46–47) → 【本節】1-3 固體(p.48–49) → 1-4 粒子觀(p.50–51) → 活動2 傳播方式 → 活動3 保溫散熱
概念鏈     溫度計液柱升降 → 水位升降(變因表) → 氣球脹縮(瓶口封死) → 銅球卡住又穿過 → 【本節要跨的一步】脹是「往外」的、洞也跟著變大 → 粒子間距變大(非粒子變大)
教材地位   過去：三下單元2 初識熱對物質的影響；五上 溫度與熱量 → 本節：把「會脹」推進到「往哪裡脹」 → 未來：2-1 熱傳導(銅環柄會燙正是傳導)；國中 熱膨脹係數
```

- 課本三節實驗結構完全平行：提問 → 假設 → 對照組／實驗組 → 討論 → 歸納。變因表、步驟圖、結論句都已印好；學生在前兩節已經跑過兩輪。
- 本節課本只做「加熱銅球」，沒有做「加熱銅環」。p.48 三個生活例（瓷磚、橋梁、鐵軌）全是「實心固體往外脹要留縫」，沒有「有洞固體」的例子——這正是本節課題的空隙。
- 銅環有金屬柄（p.49 圖），加熱銅環時柄會發燙，是下一活動 2-1 熱傳導的伏筆，本節只提「小心」，不講傳導。

**二、學生可能面臨學習的困難及發現**

1. 「脹」在學生口中是一個沒有方向的詞。畫剖面圖時，多數人會把銅環畫成「向內向外一起脹」，因此推出「洞變小」；這會在導入的共有課題（畫箭頭）那一刻現形。
2. 分不清「銅環變大」與「洞變大」是不是同一件事。有人會說「銅環變大所以洞變大」，有人說「銅環變胖所以洞變小」，兩派都用「變大」這個詞，需要反覆釐清「你說的變大是哪一圈變大？」
3. 實驗設計的混淆變因：銅球加熱後在等銅環加熱的這段時間會降溫，所以「銅球穿過去了」可能是銅球涼了而不是銅環脹了。學生做完通常不會自己想到，要靠深究把它逼出來。
4. 各組結果不一致（銅環加熱不足、銅球降溫太快）會被當成「做失敗」；要把它變成串連材料而不是收掉。
5. 蠟燭火焰加熱慢，三分鐘內學生會失去耐性開始碰器材；安全與時間管理要一起顧。

## 各節次學習活動設計的重點

本單元共 12 節，活動 1 共 4 節；本節為活動 1 第 3 節〔節次為推估〕。第 1 節做液體（錐形瓶水位）、第 2 節做氣體（氣球脹縮），學生已跑過兩輪「假設 → 對照組／實驗組 → 討論 → 歸納」，也填過兩張變因表；上一節末段已依課本 p.49 做完「加熱銅球 → 卡住 → 浸冷水 → 穿過」〔請教師確認此段是否已在前一節完成；若未完成，本節導入需多 5 分鐘先做這一段，跳躍題的實驗時間相應縮短〕。因此本節不再教變因、不再重做加熱銅球，時間全放在「加熱銅環」的預測、驗證與串連。第 4 節接 p.50–51 粒子觀，本節結尾不翻那兩頁。

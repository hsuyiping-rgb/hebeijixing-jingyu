# 學共教案（專案藍圖）

> 本檔為跨 Agent 通用的專案藍圖（AGENTS.md 開放標準）。任何 Agent 的每個 session 都應先讀本檔＋`handoff.md`。

## 專案簡介

開發並維護 **`slc-lesson-plan`**——學習共同體公開課四十分鐘教案撰寫技能。
技能依新北市自強國小「教學方案設計」制式表產出完整教案，支援共有課題／挑戰性課題兩種主軸，
涵蓋國語、數學、社會、自然四科，並把「傾聽—串連—回歸」與六大理答策略
（轉引、轉問、反問、提示、釐清、深究）嵌進教師支援欄的實際台詞與理答預想表。

本資料夾同時是該技能的**預設工作區**：`範本/` 存參照教案，`教材/` 存每次任務的課本教材，
`教案成果/` 存產出的課題設計卡與教案。

## 技能相關約定

- **`範本/` 與 `教材/` 都不進版控**，母 repo 的 `.gitignore` 已分別登錄。
  前者含 307 班座位表與 24 位學生姓名；後者是出版社課本與教師手冊內容，不公開散布。
  **換電腦 clone 後兩個資料夾都會是空的**——範本需自行補齊（否則 Step 4 跑不動），
  教材則每次任務重新取得即可。
- **`~/.claude/skills/slc-lesson-plan/` 由 chezmoi 管理**，改完技能除了複製過去，
  還要 `chezmoi re-add ~/.claude/skills/slc-lesson-plan/` 才會跨電腦同步。
- **技能的單一真實來源**是 `skills/slc-lesson-plan/`。`~/.claude/skills/slc-lesson-plan/` 是複本。
  **改技能一律先改這裡，再 `cp -r` 覆蓋 `~/.claude/skills/`**，不要反向操作。
- 目前**未同步**到 `~/.codex`、`~/.agents`。要在 Codex 也用時再說。
- `範本/` 的檔案是唯讀參照，**不要覆寫**。
- 技能的紅線繼承自 `exam-composer`：**Agent 不得輸入任何密碼、不得繞過下載保護機制。**

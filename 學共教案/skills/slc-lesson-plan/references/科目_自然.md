# 自然科學課題設計指引

> 實例支撐：`範本/自然科_巧妙的施力工具_滑輪_六年級.docx`
> （六年級〈巧妙的施力工具〉滑輪組，國北教大自然科教案甄選，本節為單元第 10~11 節）。
> 該實例的流程分四段：**導入／開展／挑戰／總結**，欄位為
> 「流程｜教師教學引導｜學生學習活動｜時間｜學習指導注意事項」。
> 映射到制式表：導入 → 導入與發現；開展 → 探究與深化；挑戰＋總結 → 挑戰與聚斂。

## 課題長相

| | 共有課題 | 挑戰性課題（跳躍伸展題） |
|---|---|---|
| 典型形式 | 觀察並記錄一個現象；照步驟做一次並寫下看到什麼；把測得的數據畫成圖 | **把真實情境的救援／解決任務丟給學生，要他們設計並繪出藍圖**：「用一個定滑輪和一個動滑輪，設計出一種以上的組合，並繪出藍圖，說明這樣能救出受困的小朋友。」 |
| 判準 | 人人都做得到、看得見的操作 | 需要分離變因或用證據支持解釋；不同小組的做法本來就會不同 |
| 陷阱 | 變成照食譜操作，做完不知道在做什麼 | 停在「因為老師說」——理答要頻繁【回歸】「你看到什麼，讓你這樣想？」 |

**善用組間差異**：各組數據或設計不一致往往被當成失敗，在學共課堂裡那正是最好的跳躍題材料。

## 跳躍伸展題的三個做法（取自實例）

1. **用補充文本建立真實情境，再布題。**
   實例讀的是〈台灣的地震〉（921 的傷亡、黃金救援時間），讀完直接接上：
   「你發現幼兒園有幾位受困的小朋友…出口被一塊超過 200 公斤的重石擋住，
   而你是當下唯一能救他們的人。你要怎麼運用學過的滑輪知識？」
   **課堂初始的靜默閱讀帶來班級氣息的沉澱**，是後面開放感官體驗與深化思考的基礎。

2. **情境放大、任務縮小，而且把縮小的理由講給學生聽。**
   情境是 200 公斤，實驗任務改成 20 公斤，教案原話：「受限於 200 公斤的重石，
   很難在真實的教室環境中呈現。因此，在以下的實驗任務中，我們將以 20kg 的重物來代替。」
   同理，「受限於測量工具，無法實際測量工作滑輪組的省力程度，改用教具滑輪加彈簧秤模擬。」
   **限制不藏起來，攤開來說，本身就是科學態度的示範。**

3. **分層：開胃菜 → 主菜 → 加菜。**
   一定一動的三種組合中，B 圖（課本圖片那種橫向連接）學生很快就想到，那是開胃菜；
   A、C 兩種上下連接才是主菜；「如果多用一個動滑輪呢？」是再上一階。
   **難度判準（來自作者的教學反思）：最高難度的挑戰應設定在 1/3 左右的人成功。**
   實例中最難的 C 組合到下課只有 2 組完成，作者判定這正是對的——
   成功者有難以言喻的喜悅，未完成者也感覺「就差那一點點」，下次會再努力。

## 學習重點代碼寫法

- 108 領綱學習表現：`tr-III-1`（推理論證）、`po-III-1`（發現問題）、`pe-III-2`（計畫與執行）等。
- 學習內容：`INa-III-1`、`INc-III-6` 等。跨科概念與探究能力雙軸都要對到。
- 舊實例用九年一貫代碼（`2-3-5-4`、`1-3-3-1`），新教案一律改用 108 領綱代碼。
- 實例的另一個好習慣：在能力指標清單中**標註「(本節課)」**，指出這一節真正打到的是哪幾條。

## 教材組織分析怎麼寫（實例的五段式）

1. 單元概念分析（概念圖）
2. **教材地位**：本單元的前面學過什麼（3 上「生活中有趣的力」、5 下「力與運動」），本單元如何延伸
3. **教材脈絡**：一條箭頭串到底——「認識槓桿 → 分析工具的槓桿結構 → 判斷省力費力 → 察覺滑輪是槓桿的變形 → 記錄拉力與上升方向 → 了解定動滑輪特性 → 生活應用」
4. **先備知識（本節教學前）**：條列學生此刻已知的四五件事
5. 學生特性分析

## 小組協同的形式

1. **先預測再操作**：各自寫下「我猜會怎樣，因為……」，操作後回頭對照——落差就是學習發生的地方。
2. **繪出設計藍圖**：小組討論後畫圖，再用教具驗證藍圖可不可行。**畫圖讓思考可見，也讓組間差異可比。**
3. **教具 vs 實物兩層**：先用教具滑輪加彈簧秤測量，再實際組裝工作滑輪拉真的重物——
   實例特別交代「各組裝設完成後要保留下來，讓學生有機會去操作，**用身體拉力去感覺**」。
4. **數據上牆**：各組結果寫在共同的表或圖上，全班一眼看到差異。

## 理答語感

自然科的理答特別倚重 **提示** 與 **深究**：

- 學生要答案時：`【提示】「回到你的記錄。你剛剛看到什麼？」`
- 學生卡在單一解法（例如只想得到橫向連接）：`【提示】「除了橫的，有沒有可能上下接？」`——給方向不給答案
- 收集不同解釋：`【轉引】「這是一種解釋。還有沒有別的可能？」`
- 面對錯誤概念不否定：`【轉問】「有人要幫他補充一下嗎？」`
- 追證據：`【深究】「你怎麼知道不是因為〇〇？要怎麼試才會知道？」`
- 學生沉默：`【等待】「你需要想一下是嗎？那你可以先找人幫忙嗎？」`

## 40 分鐘骨架（挑戰性課題，依實例改寫為單節版）

實例本身用連續兩節（共 80 分鐘）跑完三階段任務。壓縮成單節時：

| 流程 | 時間 | 內容 |
|---|---|---|
| 導入與發現 | 5–8 分 | 各自靜默閱讀補充文本建立情境 → 布挑戰題 → 說明任務的縮放與限制 |
| 探究與深化 | 20–22 分 | 小組討論並繪出設計藍圖 → 用教具操作驗證；教師巡走記錄各組差異與卡點 |
| 挑戰與聚斂 | 10–12 分 | 2–3 組分享不同藍圖 → 串連比較省力效果 → 回到記錄找證據 → 統整 |

**彈性條款**（實例的寫法值得照抄）：在「學習指導注意事項」欄註明
「本挑戰題將依教學實際進度調整，若學生在前一階段學習速度較慢，則在公開課中不進行，
調整至下一節課進行教學。」——公開課不必硬跑完，這句話要事先寫進教案。

## 安全

實例在注意事項欄明寫「須注意繩索和搬運重物時的操作安全」。
凡涉及重物、加熱、藥品、刀具、電路的課，**安全提醒必須出現在教案裡**，不是口頭交代。

# 社會科課題設計指引

> **實例支撐**：濱之鄉小學 脇坂歸晤老師社會課〈汽車產業的發展〉課例影片分析
> （15 課時單元的第 13 課，探討產業全球化的兩難）。
> 材料位置：`G:\我的雲端硬碟\和北極星境遇\學習共同體課堂影片分析\濱之鄉小學脇坂歸晤社會課\output\`
> （`analysis.txt` 分析、`transcript.txt` 逐字、`slides.pptx` 課例簡報）。
>

> 2. `transcript.txt` 是**現場中文口譯的敘述**，不是教師原話，**不可當作理答台詞的原型**。

## 課題長相

| | 共有課題 | 挑戰性課題（伸展跳躍） |
|---|---|---|
| 典型形式 | 從一份圖表／老照片／地圖／統計表讀出三件事實；把課文提到的變化排成時間軸 | **兩難（Dilemma）**：「工廠要留在國內，還是移到海外？」——兩邊都有道理，選任一邊都有人受傷 |
| 判準 | 每個人都讀得到、指得出來的資料 | **沒有標準答案**，且必須回到資料舉證；學生要能說出「我個人希望…但考慮到整體…」這種分層的話 |
| 陷阱 | 淪為找答案填空 | 變成情緒表態或空泛的辯論賽——理答要頻繁【回歸】「你這樣說，是根據哪一份資料？」 |

## 好的社會科課題怎麼長出來（取自實例的四個做法）

1. **從身邊人的故事起頭，讓知識有溫度。**
   實例先請 Miyu 的爸爸（安全氣囊開發者）到班上分享——「除了賺錢之外，人的生命安全更重要」，
   再把全班的感想整理成一張 list 回顧。接著 Misaki 說出自己父母在國內製造引擎，
   生產線一旦外移家裡的工廠就會倒。**個人故事打破知識的冰冷性，建立有溫度的學習起點。**

2. **兩難要兩邊都給足彈藥。**
   國內生產：家庭與就業、技術傳承。海外生產：人事與材料成本、國際競爭力、母公司不賺錢會拖累更多家庭。
   **兩邊都由學生說出來**，教師不評判哪邊對。

3. **用時事資料當跳躍的鷹架。**
   學生好不容易站到「不得不移往海外」時，教師拿出 2014 年《日本經濟新聞》報導：
   豐田將於 2017 年撤出澳洲工廠，2500 人失業。**打破「海外生產是一勞永逸的解方」，
   造成二度認知衝突**，學生開始討論關廠時間差（2014→2017）的用意、對當地家庭的影響、
   以及對日本名聲的傷害——同理心從本國勞工延伸到他國勞工。

4. **不以標準答案作結，留一個大問號。**
   最後展示「日本人口預測圖」：勞動人口 2055 年將大幅減少。不解釋，就下課。
   **把思考延伸到下一堂課。**

## 學習重點代碼寫法

- 學習表現：`2b-III-1`（社會參與、態度）、`3a-III-1`（探究與實作）等，代碼＋全文。
- 學習內容：`Aa-III-1`（互動與關聯）、`Cb-III-2`（生產與消費）等，依主題軸填。

## 小組協同的形式

1. **資料判讀**：一組一份（或每人一份）圖表、地圖、老照片、報導節錄，先各自圈出看到的東西，
   再互相說「我看到的跟你不一樣的地方」。**社會課最重要的就是資料**——實例的補充資料非常充足。
2. **人人都要說一次**：實例特別設計小組交流時間，讓每位學生在組內發表個人看法，
   **避免少數活躍學生壟斷發言，確保每個孩子都不是學習的「客人」**。
3. **溫柔地傾聽 > 大聲地發表**。這是學共哲學的基礎，寫進教案的教師支援欄裡。
4. **立場分派或自選**：各組拿到不同角色的資料包，分享時全班才拼得出全貌。
5. **舉證卡**：發言時要說「我的依據是第〇份資料的第〇行」，把「回歸資料」變成班級常規。

## 理答語感

社會科的理答特別倚重 **轉引**（收集多元立場）與 **回歸**（要求舉證）：

- 收集立場：`【轉引】「這是第一種看法。還有沒有想得不一樣的組？」`（連續三組不評價）
- 要求依據：`【回歸】「哪一份資料讓你這樣想？念給我們聽。」`
- 面對價值判斷：`【反問】「那你自己呢？換成是你，你會怎麼做？」`
- 學生說得太快太順：`【深究】「那反過來的人，他為什麼會那樣想？」`
- 學生講得含混：`【釐清】「再一次！」`

**等待**：實例中，學生發言緩慢或遲疑時，全班與教師都耐心等待，讓孩子把想法化為文字。
分析原話：**「教師的聆聽姿態決定了課堂的品質，以『傾聽』取代『發問』。」**
教案的教師支援欄要明寫「此處留白等待，不催、不換人」。

## 40 分鐘的一個可用骨架（挑戰性課題）

| 流程 | 時間 | 內容 |
|---|---|---|
| 導入與發現 | 8–10 分 | 回顧上節的個人故事或共同資料 → 各自讀一份共同資料圈出事實（共有課題）→ 拋出兩難題 |
| 探究與深化 | 20 分 | 各組讀資料包，討論並整理論點與依據；教師巡走，記下組間立場的差異 |
| 挑戰與聚斂 | 10–12 分 | 各組說一個「我們原本沒想到的」→ 教師投出反例資料造成二度衝突 → 回到資料驗證 → **留一個問號，不給結論** |

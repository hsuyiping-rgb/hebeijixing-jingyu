# 制式表欄位對照

> 來源：`範本/公開課教案參考格式.docx`（新北市自強國小教學方案設計）。
> 填寫語氣參照兩份實例：`範本/…106學年度 國語科公開課教案1126.docx`、
> `範本/…110學年度 數學科 公開課教案(許以平)0505-1.docx`。
> 注意：兩份實例用的是較舊的「學習活動｜教師指導｜備註」三欄表，**結構以制式表為準**，
> 實例只提供各欄該寫多細、語氣多具體的參照。

## 一、表頭

| 欄位 | 填寫要領 |
|---|---|
| 授課年級 | `〇年 〇班` |
| 授課日期 | `年月日`，可加節次 |
| 任教學科 | 領域名（國語文／數學／社會／自然科學） |
| 教學者（教案設計） | 姓名 |
| 單元名稱 | 課本單元與課名 |
| 備課成員 | 共備夥伴姓名 |
| 使用版本 | 康軒／翰林／南一／自編 |

## 二、教學設計理念

一段 150–300 字的散文，不是條列。實例的寫法是：**教材本身有什麼價值 → 學生欠缺什麼經驗 →
所以本課打算用什麼方式讓學生自己走到那裡**。學共的語氣要出現：讓學生的差異被看見、
讓學生互相聆聽、教師不代答。

## 三、核心素養

| 欄 | 填什麼 |
|---|---|
| 總綱 | 三面九項的代碼與名稱，如 `A2 系統思考與解決問題` |
| 領綱具體內涵 | 領域核心素養代碼與全文，如 `國-E-A2` |

## 四、領域課程綱要

**這是一張二維表，不是三個並排的欄位。**表格左上角是斜線表頭，印著「學習目標／學習表現／
學習內容」三個標籤（用繪圖物件畫的，不在儲存格文字裡，**填表時不要覆寫這一格**）。

三者的關係是：**學習目標源於學習內容與學習表現**——
縱軸載入本節重要的**學習內容**，橫軸列出與這場公開課有關的**學習表現**，
再依兩者整合出這堂課的**學習目標**。

| 位置 | 欄 | 填什麼 | 例 |
|---|---|---|---|
| 第 2 列右側兩格（**橫軸**） | 學習表現 | 代碼＋全文，與本節公開課直接相關者，1~2 項 | `d-III-1 報讀圓形圖，製作折線圖與圓形圖，並據以做簡單推論。` |
| 第 3 列左格（**縱軸**） | 學習內容 | 代碼＋全文，本節重要的學習內容 | `D-5-1 製作折線圖：製作生活中的折線圖。` |
| 第 3 列右側寬格（**交會處**） | 學習目標 | 由上面兩者整合出的、本節可觀察的目標，2 條以內 | `1. 能依表格資料繪製折線圖。`<br>`2. 能判斷折線圖適用於有序資料，並說出判斷的理由。` |

> ⚠️ **第 3 列的第 2、3 欄是合併儲存格**（整列只有 2 個實際格），學習目標就寫進那一格。
> 分別寫入會讓後者蓋掉前者，而 python-docx 讀回時兩欄都顯示有內容（同一格被讀兩次），
> 很容易誤判成功。`build_docx.py` 已處理，詳見下方〈填表陷阱〉。

## 五、教材組織與學生分析

三小段：

1. **文本結構分析**：國語寫意義段切分與各段功能；數學寫概念的先備與後續位置；社會寫資料的類型與立場；自然寫現象、變因與證據鏈。
2. **學生可能面臨學習的困難及發現**：**具體到概念或語詞**。實例寫法：「學生可能不認識『山胡桃、臭椿、食茱萸、楓香』等樹種，因而無法想像這些樹『枝枯椏禿』的意象。」不要寫「可能不理解課文」。
3. **部份學生特性**：指名到組別或代號的具體描述；依教師口述擴寫者標記 `〔依教師口述擴寫，請校對〕`。

## 六、教學設計理據（12 項，不得留空）

| 類 | 小項 | 填寫要領 |
|---|---|---|
| 學生 | 學生的心智水平 | 本班對本課概念的實際起點，含已會與未會 |
| 學生 | 學習方式的選擇 | 個人自讀→Pair→四人組？一人一份學習單的協同化學習？ |
| 教材 | 教具的使用策略 | 小白板、便利貼、平板投影、牌卡等，說明用它做什麼 |
| 教材 | 教材的使用價值 | 這份教材為何值得花一節課；作者、脈絡、與生活的連結 |
| 教材 | 教學目標的設計 | 與第四塊的學習目標一致，寫出為何這樣設 |
| 教材 | 學科作業的設計 | 學習單形式；學共強調「一人一份，協同化」 |
| 環境 | 教學情景的創設 | 座位形式與它服務什麼（ㄇ字型便於小組協同） |
| 環境 | 課程資源的開發 | 補充文本、實物、外部資源 |
| 教師 | 教學過程的構建 | 一句話說清本課的學習路徑，如「閱讀題目—指出關鍵詞—釐清—討論與分享」 |
| 教師 | 師生問題的生成 | **預想學生讀完後會提出的問題**，列 3–8 條，愈具體愈好 |
| 教師 | 教學活動的開展 | 活動形式的清單（音讀、標記、書寫白板、操作牌卡） |
| 教師 | 教學語言的優化 | 教師自我提醒：語速放慢、站位要能納入全班視域、細膩讀學情 |

## 七、各節次學習活動設計的重點

先用一兩句交代本單元共幾節、公開課是第幾節、前幾節做了什麼。

## 八、本節流程表（核心）

四欄：**流程｜教學活動內容｜教師支援、學習引導｜時間**

流程列固定三段：**導入與發現／探究與深化／挑戰與聚斂**。

- **教學活動內容**：寫學生在做什麼，動詞開頭（「各自輕聲閱讀題目」「小組討論確認分類條件」「各組將白板張貼於黑板並分享」）。
- **教師支援、學習引導**：**台詞＋觀察指令交錯**。台詞標記策略（`【轉問】「…」`），觀察指令如「觀察有無閱讀困難的學生與組別」「傾聽各組解法的差異」「支援困難小組與學生」。
- **時間**：每段標分鐘數，三段總和 40。

## 九、觀課資訊

授課老師／觀課班級／觀課日期／科目單元由 Step 0 帶入；觀課教師的學校與姓名留空。

## 十、觀課紀錄表

三向度 × 8 個引導問句，**原樣保留**：

| 面向 | 要項 |
|---|---|
| 1. 全班學習氣氛 | 1-1 是否有安心學習的環境？　1-2 是否有聆聽學習的環境？ |
| 2. 學生學習歷程 | 2-1 學習動機是否持續？　2-2 是否相互關注與傾聽？　2-3 是否互相協助與討論？　2-4 是否投入參與學習？　2-5 是否發現有特殊表現的學生？（學習停滯、超前和學習具潛力者） |
| 3. 學生學習結果 | 3-1 學生學習是否成立？如何發生？何時發生？　3-2 學生學習的困難之處是什麼？ |

下方兩列「學生學習紀錄」「觀課者學習與收穫」留白給觀課者。
**在此表上方**加一塊「本課觀課焦點」，寫 2–3 條指名到組別或學生的具體焦點。

## 十一、填表陷阱（Step 4 轉 docx 用）

制式表是人手排出來的表格，幾何跟肉眼看到的欄位數不一定一致。以下是已知會咬人的地方：

| 陷阱 | 現象 | 處理 |
|---|---|---|
| **二維表誤當並排欄位** | `領域課程綱要` 是橫軸（學習表現）× 縱軸（學習內容）→ 交會處（學習目標），不是三欄並排 | 依第四節的位置表填，**不要自行改動這張表的結構** |
| **斜線表頭** | 該表左上角格的三個標籤是繪圖物件，儲存格文字讀起來是空的 | 那一格**保持不動**，不要寫入任何文字 |
| **合併儲存格** | 該表第 3 列的第 2、3 欄合併，整列只有 2 個實際格。分別寫入時後者覆蓋前者，且讀回檢查會**假通過**（同一格被讀兩次，兩欄都有內容） | 學習目標寫進 `rows[2].cells[1]` 即可；驗證要以「實際格數」為準 |
| **表上沒有的區塊** | 制式表**沒有**「教學設計理據 12 項」與「理答預想表」的欄位 | 腳本另外插表，不要硬塞進既有欄位 |
| **觀課焦點的位置** | 範本的「觀課重點」段落就是本課觀課焦點該落的地方 | 插在該段之後 |
| **中文亂碼** | Windows 下讀寫 docx 直接跑會亂碼 | 一律 `python -X utf8` |
| **檔案被 Word 開著** | 輸出時 `PermissionError: [Errno 13]` | 先關掉 Word 再重跑 |

**換範本或範本改版前，先跑一次幾何檢視**，它會標出哪幾列有合併儲存格：

```bash
python -X utf8 skills/slc-lesson-plan/scripts/build_docx.py --inspect "範本/公開課教案參考格式.docx"
```

不要用「寫完再讀回來比對」當作驗證手段——合併儲存格會讓這種檢查通過。

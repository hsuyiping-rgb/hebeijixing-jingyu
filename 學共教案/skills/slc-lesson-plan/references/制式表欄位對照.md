# 制式表欄位對照

> 來源：`範本/公開課教案參考格式.docx`（教學方案設計）。
> 填寫語氣參照兩份實例：`範本/…106學年度 國語科公開課教案1126.docx`、
> `範本/…110學年度 數學科 公開課教案(許以平)0505-1.docx`。
> 注意：兩份實例用的是較舊的「學習活動｜教師指導｜備註」三欄表，**結構以制式表為準**，
> 實例只提供各欄該寫多細、語氣多具體的參照。

## 怎麼用這份檔

每一節都用同一套格式交代四件事，缺一不可：

- **寫什麼**——這一欄要回答的問題。
- **篇幅**——大概多長。超過就是在灌水，不足就是沒交代清楚。
- **合格判準**——寫完拿這條回頭檢查，過不了就重寫。
- **不要這樣寫**——已知會出現的空話與錯誤示範。

貫穿全篇的三條總則：

1. **具體到可觀察。** 凡是寫完之後無法指著課堂裡的某個人、某句話、某個動作說「就是這個」的句子，都算沒寫。
2. **教師本人才知道的事不得捏造。** 班級人數、學生個性、前幾節實際發生了什麼，一律問；問不到就標 `〔待補：…〕` 或 `〔依教師口述擴寫，請校對〕`，不要自行填一個合理的數字。
3. **推估值要標出來。** 若某個數字是我推的（例如「安靜作業超過八分鐘會分心」），而且後面的時間配置是照它排的，必須在交付回報裡點名，讓教師知道改了它就要重排。

## 一、表頭

| 欄位 | 寫什麼 | 合格判準 |
|---|---|---|
| 授課年級 | `〇年〇班`，**含班級人數** | 人數缺就標 `〔待補：班級人數〕`，不要略過——人數決定分幾組，組數決定巡走動線 |
| 授課日期 | `〇年〇月〇日（星期〇）第〇節` | 民國年；星期與節次都要有，觀課教師靠這個排課 |
| 任教學科 | 領域名（國語文／數學／社會／自然科學） | 用領綱的領域名，不是「國語」「自然」這種簡稱 |
| 教學者（教案設計） | 姓名 | — |
| 單元名稱 | 課本單元＋課名＋**本節是第幾節** | 例：`第一單元〈折線圖〉（本節為第 4 節，統整）` |
| 備課成員 | 共備夥伴姓名 | 沒有共備夥伴就寫「無」，不要留空白 |
| 使用版本 | 康軒／翰林／南一／自編 | — |

**不要這樣寫**：日期只寫「11 月」；單元只寫課名而不交代本節在單元中的位置。

## 二、教學設計理念

**寫什麼**：一段散文，回答「這一節課為什麼要這樣上」。固定三拍——
**教材本身有什麼價值 → 學生欠缺什麼經驗 → 所以本課打算用什麼方式讓學生自己走到那裡**。

**篇幅**：150–300 字，一段到兩段。**不是條列。**

**合格判準**：
- 第二拍必須指出一個**具體的落差**（「規準背得出來，遇到具體情境卻用不上」），不是泛稱「基礎不佳」。
- 第三拍必須說明教師**不做什麼**（不代答、不裁決對錯），這是學共的語氣所在。
- 讀完能回答「本課的爭點是什麼」。

**不要這樣寫**：「本課旨在培養學生的統計素養，透過小組合作提升學習興趣。」——三拍全缺，換任何一課都成立。

## 三、核心素養

**寫什麼**：總綱三面九項的代碼與名稱，配上領域核心素養的代碼與全文。

**篇幅**：**最多 2 項**，第一項為主、第二項為輔。

**合格判準**：
- 主素養必須是本節**真正在評的**那一項，不是本單元的。
- 每一項的領綱具體內涵要**抄全文**，不能只寫代碼。
- 主輔關係要在交付時對教師講明，讓他決定要不要對調。

**不要這樣寫**：一次列四五項；只寫 `數-E-B2` 而不附全文。

## 四、領域課程綱要

**這是一張二維表，不是三個並排的欄位。**表格左上角是斜線表頭，印著「學習目標／學習表現／
學習內容」三個標籤（用繪圖物件畫的，不在儲存格文字裡，**填表時不要覆寫這一格**）。

三者的關係是：**學習目標源於學習內容與學習表現**——
縱軸載入本節重要的**學習內容**，橫軸列出與這場公開課有關的**學習表現**，
再依兩者整合出這堂課的**學習目標**。

| 位置 | 欄 | 填什麼 | 例 |
|---|---|---|---|
| 第 2 列右格（**橫軸**） | 學習表現 | 代碼＋全文，與本節公開課直接相關者，**最多 2 條** | `d-III-1 報讀圓形圖，製作折線圖與圓形圖，並據以做簡單推論。` |
| 第 3 列左格（**縱軸**） | 學習內容 | 代碼＋全文，本節重要的學習內容，**最多 2 條** | `D-5-1 製作折線圖：製作生活中的折線圖。` |
| 第 3 列右格（**交會處**） | 學習目標 | 由上面兩者整合出的、本節可觀察的目標，2 條以內 | `1. 能依表格資料繪製折線圖。`<br>`2. 能判斷折線圖適用於有序資料，並說出判斷的理由。` |

**學習目標的合格判準**：每一條都要能在這 40 分鐘內**被觀課者看見**——
看見學生寫下什麼、說出什麼、改了什麼。「能理解」「能體會」不可觀察，一律改寫成
「能說出…的理由」「能依…畫出…」「能判斷…並說明」。

**不要這樣寫**：學習目標抄成整個單元的目標；或寫了三四條，一節課評不完。

> ⚠️ 這張表的幾何**改過版**：現行範本每列就是 2 個實際格（斜線表頭格＋內容格），
> 舊版是 3 欄且第 3 列的第 2、3 欄合併。兩版的填入位置相同（`rows[1].cells[1]`、
> `rows[2].cells[0]`、`rows[2].cells[1]`），但**換範本前一定要重跑 `--inspect`**，
> 不要用「寫完再讀回來比對」當驗證——合併儲存格會讓那種檢查假通過。

## 五、教材組織與學生分析

三小段，抬頭沿用範本原文。

**一、文本結構分析**（用圖形和文字表示）

- **形式：圖形優先。** 抬頭要求的就是圖，所以這一欄先放一張橫向流程圖，文字只當補充。
  圖至少畫三帶：**單元節次**（標出本節位置）、**概念鏈**、**教材地位**（過去→本單元→未來）。
  做法是在 JSON 把這欄寫成 `{"圖": {...}, "文字": [...]}`，
  `build_docx.py` 會自動畫圖插入，規格見 `scripts/structure_diagram.py`。
- **寫什麼**：這份教材的內在結構。國語寫意義段切分與各段功能；數學寫概念的先備與後續位置；社會寫資料的類型與立場；自然寫現象、變因與證據鏈。
- **合格判準**：讀完知道「本節這一小塊」在整個知識脈絡中卡在哪個位置，前面接什麼、後面通往什麼。
- **不要這樣寫**：把課文內容重述一遍。

**二、學生可能面臨學習的困難及發現**

- **寫什麼**：3–5 條，**具體到概念或語詞**。
- **篇幅**：每條一句到兩句，可編號。
- **合格判準**：每一條都答得出「這個困難會在課堂的哪一刻現形」。實例寫法：「學生可能不認識『山胡桃、臭椿、食茱萸、楓香』等樹種，因而無法想像這些樹『枝枯椏禿』的意象。」
- **不要這樣寫**：「學生可能不理解課文」「基礎較弱的學生會有困難」。

**三、特殊學生特性描述**

- **寫什麼**：指名到**組別或代號**的具體描述，涵蓋學習停滯、超前、具潛力、幾乎不發言者。
- **合格判準**：觀課教師拿著這一段能在教室裡**找得到人**。這一段補完，觀課焦點也要跟著改成指名對象。
- **來源規則**：教師口述擴寫者標 `〔依教師口述擴寫，請校對〕`；教師沒講的標 `〔待補：…〕`，**不得自行虛構學生**。

## 六、教學設計理據（四大類 12 項，不得留空）

備課要問的是「這一節課，**教師**打算怎麼教、用什麼**教材**、面對的是什麼樣的**學生**、
要營造什麼樣的**環境**」。理據表就是把這四個面向拆開來各自交代清楚，
所以**先分四大類，再在每一類下面做進一步的分析**——學生的特性、教材的特性、環境的營造。

表格固定用「類／項目／內容」三欄，**依教師→教材→學生→環境排列**，
同一類的「類」欄縱向合併成一格（`build_docx.py` 會自動處理，不必手動排）。

**共通篇幅**：每一項 2–4 句。**共通判準**：每一項都要扣回**這一節課**——
換一課還成立的句子就是廢話，重寫。

| 類 | 項目 | 填寫要領 |
|---|---|---|
| 教師 | 教學過程的構建 | 一句話說清本課的學習路徑，如「閱讀題目—指出關鍵詞—釐清—討論與分享」 |
| 教師 | 師生問題的生成 | **預想學生讀完後會提出的問題**，列 3–8 條，寫成學生會說出口的原話 |
| 教師 | 教學活動的開展 | 活動形式的清單（音讀、標記、書寫白板、操作牌卡），照課堂順序排 |
| 教師 | 教學語言的優化 | 教師自我提醒：語速放慢、站位要能納入全班視域、細膩讀學情 |
| 教材 | 教具的使用策略 | 小白板、便利貼、平板投影、牌卡等，**說明用它做什麼**，不只列品項 |
| 教材 | 教材的使用價值 | 這份教材為何值得花一節課；作者、脈絡、與生活的連結 |
| 教材 | 教學目標的設計 | 與第四塊的學習目標一致，寫出**為何這樣設** |
| 教材 | 學科作業的設計 | 學習單的實際欄位；學共強調「一人一份，協同化」 |
| 學生 | 學生的心智水平 | 本班對本課概念的實際起點，**已會什麼、未會什麼分開寫** |
| 學生 | 學習方式的選擇 | 個人自讀→Pair→四人組的實際順序與各自的用意 |
| 環境 | 教學情景的創設 | 座位形式**與它服務什麼**（ㄇ字型便於小組協同、教師站位能納入全班） |
| 環境 | 課程資源的開發 | 補充文本、實物、外部資源，寫清楚在哪一刻拿出來 |

12 項是這張表的**下限**。某一類還有值得交代的面向（例如教師的專業支援、學生的組間差異），
可以在該類下加列，加的列依然要歸進四大類之一。

**不要這樣寫**：「教具的使用策略：小白板、學習單。」——沒說用它做什麼。
「學生的心智水平：學生程度不一。」——沒有起點就沒有設計。

## 七、各節次學習活動設計的重點

**寫什麼**：本單元共幾節、公開課是第幾節、**前幾節實際做了什麼**、本節因此從哪裡接手。

**篇幅**：一段，2–4 句。

**合格判準**：觀課教師讀完知道「今天這節不會再教什麼」——
哪些技術前幾節已經處理掉了，所以本節可以把時間全放在爭點上。

**不要這樣寫**：只寫「本單元共 5 節，本節為第 4 節」就結束，沒交代前三節的落點。

## 八、本節流程表（核心）

四欄：**流程｜教學活動內容｜教師支援、學習引導｜時間**

流程列固定三段：**導入與發現／探究與深化／挑戰與聚斂**，各自對應一個主軸
（傾聽／串連／串連＋回歸），主軸寫在流程名下方。

**教學活動內容**

- **寫什麼**：學生在做什麼。每段拆成編號的小活動，各自標分鐘數。
- **合格判準**：每一個小活動都以**學生的動詞**開頭（各自輕聲讀、在方格上畫、和旁邊的人交換看、把白板貼上黑板）。主詞是老師的句子，該挪到右欄去。
- **不要這樣寫**：「教師講解折線圖的畫法」——這是教師動作，不是學生活動。

**教師支援、學習引導**

- **寫什麼**：**台詞與觀察指令交錯**。
- **台詞**：寫教師實際會說出口的話，前面標策略，如 `【轉問】「小安，你對剛才小齊說的有不同想法嗎？」`。規則：短（真實課堂常只有四五個字）、不評價、不代答、不說「錯了」、不文謅謅。
- **觀察指令**：「觀察有無閱讀困難的學生與組別」「傾聽各組解法的差異」「記下畫法不同的學生座號，作為後段串連的素材」。
- **合格判準**：每段**至少 2 個標記過的台詞**，全篇**涵蓋 ≥ 4 種**策略；每段至少 1 條觀察指令，且指令要說清楚**記下來要拿去做什麼**。
- **不要這樣寫**：「教師鼓勵學生發表」「給予適當引導」——沒有台詞就等於沒有支援。

**時間**

- 每個小活動標分鐘數，段落標小計，**三段總和恰為 40 分**。
- 兩條硬約束：**進入小組協同 ≤ 第 10 分鐘**、**全班串連 ≥ 8 分鐘**。
- 時間是照學情排的。若某個時間點是依教師口述或推估值而定，要在交付時點名。

## 九、附錄：理答預想與串連進程表（制式表沒有，另插；一張表，一個策略一列）

**寫什麼**：四欄——策略／情境｜預想的學生回應｜判讀／這一步在串什麼｜教師理答。
**同一個策略只佔一列**：列內先【單步】（JSON 鍵 `理答預想表`，多條用 ①②③ 對位），
再【串連進程】（JSON 鍵 `串連進程模擬`，三步用 1／2／3 對位）；「策略／情境」欄寫策略名＋串連的情境與目標。
列序照六策略，其餘（回歸、等待）排後面；帶括號的策略名（「提示（回歸文本）」）併進主策略。腳本自動合併，JSON 仍一條一物件。

**合格判準**：
- 單步預想**至少涵蓋「講錯」「沉默」「離題」三種狀況**；回應欄寫學生**會說出口的那句原話**；
  判讀欄說出這句話反映什麼理解狀態；策略限六策略之一；台詞是短句。
- 串連進程：轉引三步是三個不同視點，第三步才收束成更深的問題；轉問三步是「甲 → 立場不同的乙 → 丙說出差別」，
  教師不裁決；深究三步是「一筆證據 → 第二筆 → 差別／條件 → 推到不收斂的問題」。
- 「這一步在串什麼」寫的是把誰跟誰的思考串起來，不是重述台詞。
- 流程表右欄有同一條進程的骨架並註明「見附錄・串連進程 A／B／C」。

**不要這樣寫**：回應欄寫「學生回答錯誤」；台詞欄寫「教師耐心引導學生思考」；
三步都是同一個學生；教師在第二步就說「對」「很好」；同一個策略拆成好幾列。

## 十、彈性條款與安全提醒（制式表沒有，另插）

**彈性條款**：在備註處明寫一句，例如「本挑戰題將依教學實際進度調整，若學生在前一階段學習
速度較慢，則在公開課中不進行，調整至下一節課進行教學。」
**公開課不必硬跑完**，這句要事先寫進教案，不是現場臨時決定。

**安全提醒**：涉及重物、加熱、藥品、刀具、電路的課，安全提醒**必須出現在教案裡**，
不是口頭交代。

## 十一、觀課資訊

授課老師／觀課班級／觀課日期／科目單元由 Step 0 帶入；**觀課教師的學校與姓名留空**，
那是給當天到場的人自己填的。

## 十二、本課觀課焦點

**寫什麼**：2–3 條，指名到組別或學生的具體焦點，放在觀課紀錄表**上方**
（範本的「觀課重點」段落就是它該落的位置）。

**合格判準**：每一條都要指定**看誰、看哪一刻、記下什麼**。
例：「第 3 組小美在小組討論中是否曾把想法說出口？在哪一刻？」
焦點要直接對應本課的爭點與預想卡點——觀課不是看熱鬧，是替授課者蒐集他當下看不到的證據。

**不要這樣寫**：「請觀察學生的學習情形」「注意小組討論是否熱烈」。

**依賴關係**：特殊學生一欄若還是 `〔待補〕`，觀課焦點就只能寫成「就近看 1~2 位學生」，
並標 `〔待補特殊學生後，請改為指名觀察對象〕`。補齊後兩處要一起改。

## 十三、觀課紀錄表

三向度 × 8 個引導問句，**原樣保留**：

| 面向 | 要項 |
|---|---|
| 1. 全班學習氣氛 | 1-1 是否有安心學習的環境？　1-2 是否有聆聽學習的環境？ |
| 2. 學生學習歷程 | 2-1 學習動機是否持續？　2-2 是否相互關注與傾聽？　2-3 是否互相協助與討論？　2-4 是否投入參與學習？　2-5 是否發現有特殊表現的學生？（學習停滯、超前和學習具潛力者） |
| 3. 學生學習結果 | 3-1 學生學習是否成立？如何發生？何時發生？　3-2 學生學習的困難之處是什麼？ |

下方兩列「學生學習紀錄」「觀課者學習與收穫」留白給觀課者。

## 十四、填表陷阱（Step 4 轉 docx 用）

制式表是人手排出來的表格，幾何跟肉眼看到的欄位數不一定一致。以下是已知會咬人的地方：

| 陷阱 | 現象 | 處理 |
|---|---|---|
| **二維表誤當並排欄位** | `領域課程綱要` 是橫軸（學習表現）× 縱軸（學習內容）→ 交會處（學習目標），不是三欄並排 | 依第四節的位置表填，**不要自行改動這張表的結構** |
| **斜線表頭** | 該表左上角格的三個標籤是繪圖物件，儲存格文字讀起來是空的 | 那一格**保持不動**，不要寫入任何文字 |
| **合併儲存格／範本改版** | 該表舊版是 3 欄且第 3 列的第 2、3 欄合併，現行版每列 2 格。合併時分別寫入會後者覆蓋前者，且讀回檢查會**假通過**（同一格被讀兩次） | 一律寫 `rows[1].cells[1]`／`rows[2].cells[0]`／`rows[2].cells[1]`；驗證要以「實際格數」為準 |
| **表上沒有的區塊** | 制式表**沒有**「教學設計理據」與「理答預想表」的欄位 | 腳本另外插表，不要硬塞進既有欄位 |
| **觀課焦點的位置** | 範本的「觀課重點」段落就是本課觀課焦點該落的地方 | 插在該段之後 |
| **中文亂碼** | Windows 下讀寫 docx 直接跑會亂碼 | 一律 `python -X utf8` |
| **檔案被 Word 開著** | 輸出時 `PermissionError: [Errno 13]` | 先關掉 Word 再重跑 |

**換範本或範本改版前，先跑一次幾何檢視**，它會標出哪幾列有合併儲存格：

```bash
python -X utf8 skills/slc-lesson-plan/scripts/build_docx.py --inspect "範本/公開課教案參考格式.docx"
```

不要用「寫完再讀回來比對」當作驗證手段——合併儲存格會讓這種檢查通過。

# 國語科課題設計指引

> 實例支撐：`範本/…106學年度 國語科公開課教案1126.docx`（六年級〈秋去秋來〉，徐仁修）、
> 宇津木台小學校五年級國語指導案。

## 課題長相

| | 共有課題 | 挑戰性課題（伸展跳躍） |
|---|---|---|
| 典型形式 | 找出各意義段的關鍵詞（句）2–5 個；用不超過 100 字寫出本文大意；在文本旁標記描寫〇〇的段落 | 針對一句難句的詮釋：「作者說『秋不告而別，不帶走什麼，似乎又帶走什麼』，這裡的『什麼』可能是指什麼？」／重新為本文命名並說明理由／情感轉折的成因 |
| 判準 | 人人都能動筆，答案在文本裡找得到 | 沒有單一標準答案，但**必須回得到文本找依據** |
| 陷阱 | 淪為抄寫課文 | 變成天馬行空的感想大會——所以理答要頻繁使用【回歸】「你是從課文的哪裡看出來的？」 |

> 上表的挑戰性課題都是**加法**。文本是事件鏈或多重論據時，改用下一節的**減法課題**更有力。

## 減法課題：用取捨逼出文本裡的關聯

> 實例支撐：`教案成果/五年級_國語_蚊帳大使_20260910/`（康軒五上第 1 課〈蚊帳大使〉，
> 挑戰性課題「只能留三件事」）。

上表列的典型跳躍題（難句詮釋、重新命名、情感轉折）都是**加法**——請學生多說一點。
加法題有個結構性弱點：**學生可以靠感想繞過文本**，說得誠懇就過關了，於是退化成感想大會。

**減法課題**反過來：給一個非取捨不可的限制，請學生**刪掉**文本裡的某些元素。
刪除本身沒有標準答案，但每一次刪除都得證明「沒有它，後面照樣成立」——
而那個證明只能回課文找。文本裡原本看不見的**關聯**，就是在這個時候現形的。

### 什麼時候用

課文是**事件鏈、因果鏈或多重論據**的結構時最有效。判準很簡單：
如果照課本的問法直接問「這些東西彼此有什麼關聯」，學生會給出正確但空的答案
（「都是為了幫助別人」），那就換成減法題。

記敘文的事件序、說明文的並列論據、傳記的生平階段，都適用。
純寫景抒情、單一場景的短文則不適用——沒有可刪的結構，刪了只剩感覺。

### 怎麼設計

1. **先數出可刪的單位**，數量控制在 5～7 個（太少沒得選，太多會亂）。
   單位要從課文裡整理出來、投影給全班看，讓每個人手上是同一份清單。
2. **限制要硬**：「只能留三件」比「刪掉不重要的」有力得多。
   留下的數量抓總數的一半左右。
3. **附一個目的條件**：「還有沒有可能達成〇〇？」——沒有這個條件，刪除就只是喜好排序。
4. **要求每一次刪除都標出課文段落**，這是防止感想大會的閘門。
5. **加菜那一層固定是回頭看**：「被你刪掉的那件，真的不重要嗎？」
   樞紐元素（那個「刪了後面就斷」的東西）通常就藏在這一問裡。

分層對照三段難度（判準見 `SKILL.md`：最高難度設定在**約 1/3** 的組別能完成）：

| 層 | 學生做得到什麼 | 〈蚊帳大使〉的實例 |
|---|---|---|
| 開胃菜 | 刪掉看起來重複的元素 | 義賣和演講都是募款，刪一個 |
| 主菜 | 發現樞紐元素，刪了後面就斷 | 獎狀 → 貝克漢貼上網站 → 富豪願意讀信 |
| 加菜 | 說出這條鏈的運作原理 | 行動之所以有效，是因為它讓更多人**看見** |

### 理答上的注意

減法題最常見的兩種偏移，各有固定的接法：

- **用「重要／不重要」的感覺投票**：`【深究】「你是從課文的哪裡看出來的？」`
- **把「結果」當成可刪的「元素」刪來刪去**（例：把「蓋茲捐三百萬」當成主角的行動）：
  `【提示】「回到題目。題目說的是誰做的事？」`——反覆要求回到題目，不說「錯了」。

### 變形

- **只能加一件**：課文沒寫、但你認為主角應該做的事，加一件並說明它會接在哪一段之後。
- **換順序**：把兩件事對調，故事還成立嗎？（適合因果不可逆的文本）
- **刪一整段**：哪一段刪掉最不影響全文？——這一版直接指向段落功能。

## 學習重點代碼寫法

- 學習表現：`5-III-4`（閱讀）、`2-III-2`（聆聽）等，代碼＋全文。
- 學習內容：`Ad-III-2`（篇章）、`Ac-III-1`（句段）等。
- 舊實例可能用九年一貫代碼（`5-3-3-1`），新教案一律改用 108 領綱代碼。

## 小組協同的形式

**回到文本找依據**是國語科協同的核心動作。常見安排：

1. **多次閱讀**（實例做到 6 次）：各自靜默讀 → 各自輕聲讀 → Pair 朗讀／聆聽 → 指名朗讀 → 帶著任務再讀並劃記。
   每次閱讀給一個不同的任務，避免跳讀與無意願。
2. **音讀分享**：用讀出聲的方式分享各自標記的段落，讓斷句、語氣、抑揚頓挫的差異被聽見——**聲音的差異就是理解的差異**。
3. **白板摘要**：小組把大意寫在軟性小白板，張貼黑板，全班比較各組的異同。
4. **便利貼提問**：各自寫下讀不懂的地方，小組先處理，處理不掉的丟給全班。

## 理答語感

國語科的理答特別倚重 **釐清** 與 **回歸**：

- 學生講得語意混亂時：`【釐清】「再一次！」`（不要說「你的意思是不是…」，那是代答）
- 學生離開文本時：`【回歸】「這句話在課文的哪裡？讀給我們聽。」`
- 學生答對但停在表層：`【深究】「作者為什麼不直接說出來？」`
- 隱藏已知：`【反問】「欸，我不懂。什麼叫『沒有為兩兄弟的選擇做出判斷』？」`

| 流程 | 時間 | 內容 |
|---|---|---|
| 導入與發現 | 8 分 | 各自靜默讀 → 輕聲讀 → 說出課題：帶著〇〇的問題再讀一次並劃記 |
| 探究與深化 | 20 分 | Pair 音讀分享劃記處的差異 → 四人組討論，寫上小白板 |

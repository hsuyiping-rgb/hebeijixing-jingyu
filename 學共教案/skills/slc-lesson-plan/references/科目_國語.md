# 國語科課題設計指引

> 實例支撐：`範本/…106學年度 國語科公開課教案1126.docx`（六年級〈秋去秋來〉，徐仁修）、
> 宇津木台小學校五年級國語指導案。

## 課題長相

| | 共有課題 | 挑戰性課題（伸展跳躍） |
|---|---|---|
| 典型形式 | 找出各意義段的關鍵詞（句）2–5 個；用不超過 100 字寫出本文大意；在文本旁標記描寫〇〇的段落 | 針對一句難句的詮釋：「作者說『秋不告而別，不帶走什麼，似乎又帶走什麼』，這裡的『什麼』可能是指什麼？」／重新為本文命名並說明理由／情感轉折的成因 |
| 判準 | 人人都能動筆，答案在文本裡找得到 | 沒有單一標準答案，但**必須回得到文本找依據** |
| 陷阱 | 淪為抄寫課文 | 變成天馬行空的感想大會——所以理答要頻繁使用【回歸】「你是從課文的哪裡看出來的？」 |

## 學習重點代碼寫法

- 學習表現：`5-III-4`（閱讀）、`2-III-2`（聆聽）等，代碼＋全文。
- 學習內容：`Ad-III-2`（篇章）、`Ac-III-1`（句段）等。
- 舊實例可能用九年一貫代碼（`5-3-3-1`），新教案一律改用 108 領綱代碼。

## 小組協同的形式

**回到文本找依據**是國語科協同的核心動作。常見安排：

1. **多次閱讀**（實例做到 6 次）：各自靜默讀 → 各自輕聲讀 → Pair 朗讀／聆聽 → 指名朗讀 → 帶著任務再讀並劃記。
   每次閱讀給一個不同的任務，避免跳讀與無意願。
2. **音讀分享**：用讀出聲的方式分享各自標記的段落，讓斷句、語氣、抑揚頓挫的差異被聽見——**聲音的差異就是理解的差異**。
3. **白板摘要**：小組把大意寫在軟性小白板，張貼黑板，全班比較各組的異同。
4. **便利貼提問**：各自寫下讀不懂的地方，小組先處理，處理不掉的丟給全班。

## 理答語感

國語科的理答特別倚重 **釐清** 與 **回歸**：

- 學生講得語意混亂時：`【釐清】「再一次！」`（不要說「你的意思是不是…」，那是代答）
- 學生離開文本時：`【回歸】「這句話在課文的哪裡？讀給我們聽。」`
- 學生答對但停在表層：`【深究】「作者為什麼不直接說出來？」`
- 隱藏已知：`【反問】「欸，我不懂。什麼叫『沒有為兩兄弟的選擇做出判斷』？」`

## 40 分鐘的一個可用骨架（共有課題）

| 流程 | 時間 | 內容 |
|---|---|---|
| 導入與發現 | 8 分 | 各自靜默讀 → 輕聲讀 → 說出課題：帶著〇〇的問題再讀一次並劃記 |
| 探究與深化 | 20 分 | Pair 音讀分享劃記處的差異 → 四人組討論，寫上小白板 |
| 挑戰與聚斂 | 12 分 | 各組張貼並音讀分享 → 教師串連差異 → 回到文本驗證 |

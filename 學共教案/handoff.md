## ⚠️ 注意事項

- **母 repo `hebeijixing-jingyu` 是 PUBLIC。** `範本/`（含 307 班 24 位學生姓名）與
  `教材/`（出版社課本）已排除版控。**課文附件同樣不進版控**：
  課文存 `附件_課文.json`，`build_docx.py --附件` 另產 `教案（含課文附件）.docx`，
  兩者都被 `.gitignore` 擋下。**版控的 `教案.docx`／`教案.md` 一律不含課文**；
  自己設計的學習單則照常進版控。推之前用 `python -X utf8` 讀 docx 確認一次比較保險。
- **`範本/公開課教案參考格式.docx` 不在版控裡，只存在這台電腦（DESKTOP-31QBU95）。**
  它是 `build_docx.py` 的填表對象，沒有它整個 Step 4 跑不動。
  **換電腦前要手動把 `範本/` 整個帶過去**（隨身碟或私有雲端，不要推進 public repo）。
  拿到任何一份範本都先跑 `build_docx.py --inspect` 確認幾何，不要假設它跟這裡寫的一樣。
- **技能的單一真實來源是 `skills/slc-lesson-plan/`**，`~/.claude/skills/` 是複本，
  且該複本由 chezmoi 管理——改完要 `cp -r` 過去，再 `chezmoi re-add`。
  注意 `chezmoi re-add` **不會加入新檔**，新增檔案要用 `chezmoi add`。
- **dotfiles repo 會有別台電腦推上來的 commit**。本次 push 就被擋過一次，
  `git rebase origin/main` 後才推得上去。推之前先 `git fetch`。
- 制式表三段流程是**導入與發現／探究與深化／挑戰與聚斂**。
  「伸展跳躍」是描述課題難度的詞，**不是流程名**。
- **`領域課程綱要` 是二維表**：橫軸學習表現 × 縱軸學習內容 → 交會處學習目標，
  左上角斜線表頭是繪圖物件，**不要覆寫**。驗證要以 `Filler.distinct()` 的實際格數為準，
  「寫完再讀回來比對」會假通過。
- **標楷體沒有 ①②③ 這類圈碼**——PIL 畫圖時會直接消失（`structure_diagram.py` 的圖裡別用）。
  Word 裡有字型備援可以顯示，但仍要留意。
- 讀寫 docx 一律加 **`python -X utf8`**，否則中文亂碼。
- **shell heredoc 寫長 python 腳本會被截斷**，長腳本改用 Write 工具寫成檔案再執行。
- **Git Bash 的 `/tmp` 對 Windows 原生 python 不可見**，跨工具傳檔用完整 Windows 路徑
  （本次又踩到一次，用 scratchpad 的絕對路徑解決）。
- **PowerShell here-string 語法 `@'…'@` 在 Bash 工具裡不成立**——本次 commit 訊息因此多吃一個
  `@`，事後 amend 修掉。Bash 工具寫多行訊息請用 heredoc 存檔再 `git commit -F`。
- **改檔與 `git add` 不要寫在同一個指令裡**，提交前先看 `git diff --cached`。

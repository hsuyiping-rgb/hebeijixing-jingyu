## ⚠️ 注意事項

- **版面字型是新細明體**（依使用者定稿），不是公文常見的標楷體；要換改 `build_docx.py` 的 `BODY_FONT`。
- **`.git/packed-refs.lock` 殘留鎖檔仍在母 repo**（`和北極星境遇/.git/`）。commit 會噴警告但成功。
  確認沒 git 程序時 `rm` 掉即可。**它在母 repo，不在 `學共教案/`。**
- **母 repo `hebeijixing-jingyu` 是 PUBLIC。** 不進版控的五類：`範本/`、`教材/`、課文附件、
  課本圖附件（`附件_課本*`、`*（含課本圖）.docx`）、`學共教案/tmp/`。推之前用 `git add -An` 空跑一次。
- **產含圖版與無圖版要各跑一次**：含圖版不帶旗標、輸出檔名帶「（含課本圖）」；無圖版加 `--無圖`、輸出 `教案.docx`。
- **auto mode 的權限分類器會擋 commit/push**，若使用者當輪沒明說要提交。做完先回報、等使用者說「commit」再動。
- **`範本/公開課教案參考格式.docx` 只在這台電腦（DESKTOP-31QBU95）。** 換電腦要手動帶 `範本/`。
- **輸出的 docx 被 Word 開著會 `PermissionError`**，看到 `~$…docx` 鎖檔就先請使用者關掉；
  本輪的作法是先輸出到暫名，關掉後再覆蓋。
- **LibreOffice 渲染檢查**：`"/c/Program Files/LibreOffice/program/soffice.exe" --headless --convert-to pdf`，
  再用 PyMuPDF 出縮圖拼 contact sheet 看整體版面。
- **技能的單一真實來源是 `skills/slc-lesson-plan/`**，`~/.claude/skills/` 是複本，由 chezmoi 管。
  改完 `cp` 過去，既有檔 `chezmoi re-add`、**新檔要 `chezmoi add`**。
- 制式表三段流程是**導入與發現／探究與深化／挑戰與聚斂**。「伸展跳躍」是難度用詞。
- **`領域課程綱要` 是二維表**，左上角斜線表頭是繪圖物件，**不要覆寫**。
- 讀寫 docx 一律加 **`python -X utf8`**；長 python 腳本用 Write 寫檔再跑，不用 heredoc。

  驗證要以 `Filler.distinct()` 的實際格數為準。
- 讀寫 docx 一律加 **`python -X utf8`**，否則中文亂碼。
- `範本/宇津木台…教案1.pdf` 與 `…2.pdf` 是**同一份指導案的第 1、2 頁**，掃描無文字層，
  要用 `fitz` 轉 PNG 後視覺讀取。
- **shell heredoc 寫長 python 腳本會被截斷**（bash 報 "delimited by end-of-file"），
  長腳本改用 Write 工具寫成檔案再執行。
- **Git Bash 的 `/tmp` 對 Windows 原生 python 不可見**，跨工具傳檔用完整 Windows 路徑。
- **改檔與 `git add` 不要寫在同一個指令裡**。本 session 發生兩次：一次漏掉三個檔案的編輯

## ⚠️ 注意事項

- **`.git/packed-refs.lock` 殘留鎖檔仍在母 repo**（`和北極星境遇/.git/`，9/10 20:01 的 0 byte 檔）。
  每次 commit 噴警告但都成功、push 也都成功。本輪查到有一個 `git.exe` 程序在跑所以沒刪；
  確認沒 git 程序時 `rm` 掉即可。**注意它在母 repo，不在 `學共教案/`。**
- **母 repo `hebeijixing-jingyu` 是 PUBLIC。** 不進版控的五類：`範本/`、`教材/`、
  課文附件（`附件_課文.*`、`*（含課文附件）.docx`）、課本圖附件（`附件_課本*`、`*（含課本圖）.docx`）、
  `學共教案/tmp/`。推之前用 `git add -An` 空跑一次。
- **產含圖版與無圖版要各跑一次**：含圖版不帶旗標、輸出檔名帶「（含課本圖）」；無圖版加 `--無圖`、輸出 `教案.docx`。
- **auto mode 的權限分類器會擋 commit/push**，若使用者當輪沒明說要提交。做完先回報、等使用者說「commit」再動。
- **`範本/公開課教案參考格式.docx` 只在這台電腦（DESKTOP-31QBU95）。** 換電腦要手動帶 `範本/`。
- **LibreOffice 渲染時流程表第一列會整列推到下一頁**（範本最小列高 7338 twips），Word 開起來會自動跨頁，
  不是腳本問題。渲染用 `"/c/Program Files/LibreOffice/program/soffice.exe" --headless --convert-to pdf`。
- **輸出的 docx 被 Word 開著會 `PermissionError`**，看到 `~$教案.docx` 鎖檔就先請使用者關掉。
- **技能的單一真實來源是 `skills/slc-lesson-plan/`**，`~/.claude/skills/` 是複本，由 chezmoi 管。
  改完 `cp` 過去，既有檔 `chezmoi re-add`、**新檔要 `chezmoi add`**。
  複本裡多一個真實來源沒有的 `build_docx.py`（在技能根目錄，非 `scripts/`），疑似舊殘檔，下次整理。
- **`chezmoi status` 還堆著別的變更**（`classroom-video-analysis`、`esa-meeting-minutes`、`slc-skill` 等），不是本專案動的。
- 母 repo 根目錄有未追蹤的 `怎樣解題前言.pdf`，不屬本專案，沒碰。
- 制式表三段流程是**導入與發現／探究與深化／挑戰與聚斂**。「伸展跳躍」是難度用詞。
- **`領域課程綱要` 是二維表**，左上角斜線表頭是繪圖物件，**不要覆寫**。
- 讀寫 docx 一律加 **`python -X utf8`**；長 python 腳本用 Write 寫檔再跑，不用 heredoc。
- **改檔與 `git add` 不要寫在同一個指令裡**，提交前先看 `git diff --cached`。

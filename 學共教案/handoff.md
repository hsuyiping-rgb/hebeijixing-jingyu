## ⚠️ 注意事項

- **`.git/packed-refs.lock` 有一個 20:01 留下的 0 byte 殘留鎖檔。**
  兩次 commit 都成功，但每次都噴 `Unable to create packed-refs.lock`。
  **push 時可能會被它擋住。** 確認沒有其他 git 程序在跑之後手動刪掉即可，本輪沒有擅自刪。
- **母 repo `hebeijixing-jingyu` 是 PUBLIC。** 不進版控的有四類：
  `範本/`（含 307 班 24 位學生姓名）、`教材/`（出版社課本）、
  課文附件（`附件_課文.*`、`*（含課文附件）.docx`）、
  **課本圖附件（`附件_課本*`、`*（含課本圖）.docx`，本輪新增）**。
  推之前用 `git add -An` 空跑一次，確認要進版控的只有該進的那幾個檔。
- **讀教材的圖一定要裁切放大**，PDF 整頁縮圖看得到「有一條鋒面」卻看不出它在哪、朝哪個方向。
  用 PyMuPDF：`p.get_pixmap(matrix=fitz.Matrix(4,4), clip=fitz.Rect(...)).save(png)` 再用 Read 讀那張 png。
  （做法已寫進 SKILL.md Step 1。）
- **`範本/公開課教案參考格式.docx` 不在版控裡，只存在這台電腦（DESKTOP-31QBU95）。**
  沒有它整個 Step 4 跑不動。換電腦前要手動把 `範本/` 整個帶過去。
- **輸出的 docx 被 Word 開著會 `PermissionError`**，本輪踩到一次（重跑修正版時）。
  請使用者關掉再重跑；驗證期間可先輸出到 scratchpad。
- **技能的單一真實來源是 `skills/slc-lesson-plan/`**，`~/.claude/skills/` 是複本，
  且該複本由 chezmoi 管——改完要 `cp -r` 過去，再 `chezmoi re-add`。
  `chezmoi re-add` **不會加入新檔**，新增檔案要用 `chezmoi add`。
- **`chezmoi status` 還有別的變更堆著**（`slc-skill`、`classroom-video-analysis`、
  `esa-meeting-minutes` 等），不是本輪動的。dotfiles push 前先看清楚。
- 制式表三段流程是**導入與發現／探究與深化／挑戰與聚斂**。「伸展跳躍」是難度用詞，不是流程名。

  驗證要以 `Filler.distinct()` 的實際格數為準。
- 讀寫 docx 一律加 **`python -X utf8`**。
- **shell heredoc 寫長 python 腳本會被截斷**，長腳本改用 Write 工具寫成檔案再執行。
- **改檔與 `git add` 不要寫在同一個指令裡**，提交前先看 `git diff --cached`。
